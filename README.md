# BearSched

[**Live App**](https://bearsched.vercel.app)

BearSched is a course catalog and schedule builder app for WashU students. This repository hosts the frontend, which displays course data collected by the [scraper](https://github.com/wuscheduler/scraper). The app is entirely static and does not require a backend.

## Development

To run the app locally, clone the repo and run the following:

```sh
yarn install
yarn dev
```
